# Скріншоти для instruction-bot-duplicate-report

Документ: `docs/sales/special-cases/instruction-bot-duplicate-report.md`

Покладіть файли сюди під точно такими іменами — документ уже на них посилається.

## ⚠️ Перед завантаженням: обов'язкова ретуш

На всіх скріншотах видно реальні дані покупця. Перед публікацією **замажте або замініть**:

- номери телефонів покупця (`380501960018`, `+380501960018`);
- ПІБ покупця (`Антон Харитонов`, `х Антон`);
- номери карток лояльності (`400017841`, `400000036`, `4000000135395`);
- `Member ID` і `URL картки` на екрані картки лояльності;
- дату народження та `OneBox id` на картці клієнта.

**Залишити видимим** (це і є сенс скріншота): статуси, стани заявок, лічильники,
суми балансів, назви кнопок, назву магазину.
