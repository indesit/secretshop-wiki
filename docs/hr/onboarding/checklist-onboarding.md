## День 1 — Вхід

**Виконує: Директор**

- [ ] Підготовлено робоче місце (форма, бейдж, доступи)
- [ ] Проведено ознайомлювальну зустріч (компанія, команда, Wiki, матриця ескалації)
- [ ] Призначено наставника
- [ ] Підписано необхідні документи (TODO: уточнити перелік)

**Виконує: Наставник**

- [ ] Проведено екскурсію по магазину (зали, склад, каса, службові приміщення, аварійні виходи)
- [ ] Показано розташування робочих інструментів (цінники, пакети, термінали)
- [ ] Пояснено правила зовнішнього вигляду та поведінки
- [ ] Новачок ознайомився з матрицею ескалації

---

## Дні 2–3 — Товар і сервіс

**Виконує: Наставник**

- [ ] Проведено огляд асортименту по категоріях
- [ ] Пояснено стандарт вітання та відкриття розмови з клієнтом
- [ ] Показано повний цикл обслуговування (наставник — новачок спостерігає)
- [ ] Новачок ознайомився з SOP: Відкриття та закриття магазину

**Точка перевірки (кінець Дня 3) — Наставник перевіряє:**

- [ ] Знає де знаходяться основні категорії товарів
- [ ] Може пояснити 3–5 ключових продукти своїми словами
- [ ] Знає кому передати клієнта при складному питанні

---

## Дні 4–5 — Каса та повернення

**Виконує: Наставник**

- [ ] Показано відкриття касової зміни (наставник — новачок спостерігає)
- [ ] Пояснено типи оплати
- [ ] Проведено один продаж з реальним клієнтом (наставник веде)
- [ ] Пояснено базові правила повернення та обміну
- [ ] Пояснено коли не приймати рішення самостійно і кликати КЗ

**Перевірка директора (кінець першого тижня):**

- [ ] Загальне враження: задовільно / потребує уваги *(підкреслити)*
- [ ] Наставник підтвердив готовність до наступного етапу
- [ ] Зафіксовано питання або проблеми: \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

Підпис директора: \_\_\_\_\_\_\_\_\_\_ Дата: \_\_\_\_\_\_\_\_\_\_

## Тижні 2–4 — Самостійна практика під наглядом

- [ ] Новачок виконує касові операції під наглядом

## День 30 — Підсумкова оцінка

**Виконує: Директор**

Мінімальний рівень знань — перевірити усно або на практиці:

- [ ] Знає асортимент і пояснює ключові категорії товарів
- [ ] Виконує повний цикл продажу самостійно
- [ ] Знає правила повернення та обміну, коли передавати клієнта КЗ
- [ ] Відкриває та закриває касову зміну
- [ ] Знає де знаходиться Wiki і як нею користуватися
- [ ] Знає матрицю ескалації

**Рішення директора:**

- [ ] Адаптацію завершено. Співробітник готовий до самостійної роботи.
