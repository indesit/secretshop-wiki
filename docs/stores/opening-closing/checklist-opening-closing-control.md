# Чекліст контролю відкриття та закриття магазину

> [!WARNING]
> Цей документ має статус `draft`. Не є офіційним до підтвердження редактором.

**Коли використовується:** щодня при відкритті магазину через налаштовану Google Form ранкового чекліста; при закритті — через чекліст закриття / вечірню форму, якщо вона використовується.

**Відповідальний:** продавець, який першим відкриває магазин; КЗ / останній співробітник, який закриває магазин.

> [!IMPORTANT]
> Якщо пункт з блоку «критична готовність» не виконано — не чекати мовчки. Зафіксувати фактичний статус у Google Form протягом **2 хвилин** після виявлення: не ставити галочку «готово», якщо пункт не виконаний.

---

## Відкриття: критична готовність

- [ ] Я прийшов/прийшла до магазину завчасно до офіційного відкриття.
- [ ] Сигналізацію знято, доступ до магазину є.
- [ ] Робоче освітлення увімкнено.
- [ ] Робочі розетки / автомати / тумблери увімкнені.
- [ ] Якщо є зарядна станція: вона підключена до розетки.
- [ ] Якщо є зарядна станція: сама станція увімкнена кнопкою живлення.
- [ ] Якщо є зарядна станція: є індикація заряду / заряджання.
- [ ] Комп'ютер увімкнувся.
- [ ] Інтернет працює.
- [ ] Касове ПЗ / ПРРО / BAF / Ops запущено або проблема зафіксована.
- [ ] Платіжний термінал працює або проблема зафіксована.
- [ ] Касову зміну відкрито або у Google Form вказано, чому це неможливо.
- [ ] Звірку початку зміни виконано за касовим SOP.
- [ ] Магазин готовий проводити продажі.
- [ ] Google Form ранкового чекліста відправлена з фактичними статусами всіх критичних пунктів.

## Якщо комп'ютер не вмикається

- [ ] Зафіксовано час першого виявлення проблеми: `TODO: час`.
- [ ] Перевірено тумблер / автомат розеток.
- [ ] Перевірено кабель живлення комп'ютера.
- [ ] Перевірено, чи увімкнена зарядна станція.
- [ ] Перевірено індикацію заряду / заряджання станції.
- [ ] Якщо за 2 хвилини проблема не вирішилась — у Google Form не поставлено галочку «комп'ютер увімкнувся / BAF запущено», а в коментарі вказано проблему.
- [ ] У Google Form вказано: магазин, час виявлення, що не працює, стан живлення, що вже зроблено, чи зупинені продажі.

## Відкриття: торговий зал

- [ ] Торговий зал чистий і без сторонніх предметів.
- [ ] Вітрина та POS-матеріали в порядку.
- [ ] Примірочні готові.
- [ ] Вхід / ролети / замки відкриті згідно з правилами ТРЦ.
- [ ] Рекламна конструкція / манекен виставлені, якщо це передбачено для магазину.

---

## Закриття: каса та операції

- [ ] Останній клієнт завершив обслуговування.
- [ ] Вхід заблоковано після завершення роботи з клієнтами.
- [ ] Касову зміну закрито.
- [ ] Звірку кінця зміни виконано.
- [ ] Усі службові операції / повернення / переміщення, які мали бути завершені сьогодні, зафіксовані.

## Закриття: живлення та обладнання

- [ ] Робочі програми закрито коректно, якщо це потрібно процедурою.
- [ ] Обладнання, яке має бути вимкнене на ніч, вимкнено.
- [ ] Критичне обладнання, яке має живитися або заряджатися до ранку, залишено з живленням.
- [ ] Якщо є зарядна станція: станція підключена до живої розетки.
- [ ] Якщо є зарядна станція: станція увімкнена і заряджається.
- [ ] Автомат / тумблер, який живить зарядну станцію, **не вимкнено**.
- [ ] Якщо невідомо, який автомат що живить — нічого не вимикали без підтвердження КЗ.

> [!CAUTION]
> Не вимикати автомат / тумблер на розетки «просто на ніч», якщо він може живити зарядну станцію, комп'ютер, касу, роутер або інше критичне обладнання.

## Закриття: приміщення та підтвердження

- [ ] Торговий зал, підсобка та примірочні перевірені.
- [ ] Світло вимкнено згідно зі схемою магазину; чергове світло залишено, якщо потрібно.
- [ ] Двері / ролети / замки закриті.
- [ ] Сигналізацію поставлено.
- [ ] Закриття зафіксовано у чеклісті закриття / вечірній Google Form зі статусом каси та критичного живлення.

## Поля Google Form ранкового чекліста

Форма має фіксувати не повідомлення в чаті, а фактичні контрольні галочки / відповіді:

- магазин;
- дата і час відправки форми;
- комп'ютер увімкнувся: так / ні;
- BAF / робочі системи запущені: так / ні;
- каса / ПРРО готові: так / ні;
- платіжний термінал працює: так / ні;
- світло є / робоче освітлення увімкнено: так / ні;
- зарядна станція, якщо є: підключена / увімкнена / заряджається;
- магазин готовий проводити продажі: так / ні;
- якщо «ні» по критичному пункту — час виявлення, що саме не працює, що вже перевірено, чи зупинені продажі.
