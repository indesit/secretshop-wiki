# Інструкція: Як повідомляти про проблему в магазині

> [!WARNING]
> Цей документ має статус `draft`. Не є офіційним до підтвердження редактором.

## Мета

Навчити продавця правильно фіксувати проблему і надсилати структурований notice — щоб отримувач одразу розумів що сталося, якого масштабу проблема і чи потрібна його участь.

## Головне правило

Повідомлення про проблему — це не прохання вирішити. Це **фіксація факту** з достатньою інформацією для прийняття рішення.

---

## Три запитання перед відправкою

Перш ніж написати повідомлення — дай собі відповідь на три запитання:

**1. Що саме не працює?**
Конкретно: освітлення / каса / інтернет / термінал / вентиляція.
Не «щось не так» або «проблема з обладнанням».

**2. Тільки в нас чи ширше?**
Перевір: чи є ця проблема у сусідніх магазинах або по всьому ТРЦ?
- Якщо тільки у нас → проблема внутрішня, вирішується силами магазину або сервісу.
- Якщо у сусідів теж → проблема зовнішня (ТРЦ, мережа, постачальник), вирішується адміністрацією ТРЦ.

**3. Чи можемо продовжувати роботу?**
Так / ні / частково.

## Шаблон notice

```
🔴 / 🟡 / 🟢 [Назва проблеми]

Магазин: [назва]
Час виявлення: [час]
Що не працює: [конкретно]
Масштаб: тільки наш магазин / також сусіди / весь ТРЦ
Робота магазину: продовжуємо / частково / зупинена
Що вже зроблено: [дія або «нічого»]
```

### Приклад — правильно

```
🟡 Не працює освітлення і телевізор

Магазин: Blockbuster
Час виявлення: 09:59
Що не працює: головне світло і телевізор
Масштаб: також сусідні магазини — схожа ситуація по ТРЦ
Робота магазину: продовжуємо, але темно
Що вже зроблено: перевірено щиток — все включено
```

### Приклад — неправильно

```
Не вмикається головне світло
[пауза 7 хвилин]
телевізор також не вмикається
```

> Другий варіант не дає отримувачу нічого — невідомий масштаб, невідомо чи перевіряли щиток, невідомо чи можна працювати.

## Куди надсилати

| Ситуація | Кому |
|---|---|
| Будь-яка проблема | КЗ — першим завжди |
| Масштаб: весь ТРЦ | КЗ → адміністрація ТРЦ (TODO: додати контакт) |
| Масштаб: тільки наш магазин, критично | КЗ → директор → сервісна служба |
| Масштаб: тільки наш магазин, некритично | КЗ фіксує, вирішує в робочому порядку |

> [!NOTE]
> Продавець надсилає notice і продовжує роботу. Вирішення проблеми — компетенція КЗ або директора. Продавець не має самостійно шукати майстра або дзвонити в адміністрацію ТРЦ.

---

## Як визначити колір

| Колір | Коли |
|---|---|
| 🔴 Критично | Продажі зупинені: каса не працює, немає електрики, неможливо обслуговувати клієнтів |
| 🟡 Серйозно | Робота можлива, але ускладнена: темно, немає інтернету, не працює один термінал |
| 🟢 Незначно | Дрібна несправність, не впливає на клієнтів і продажі |

---

## Після того як надіслав notice

Твоя задача виконана. Далі:
- КЗ приймає рішення і координує.
- Якщо КЗ не відповідає протягом 5 хвилин на 🔴 — зателефонуй.
- Якщо ситуація змінилась (стало гірше або вирішилось) — надішли оновлення тим самим шаблоном.
