# Регламент: Типи чеків і правила їх застосування

> [!WARNING]
> Цей документ має статус `draft`. Не є офіційним до підтвердження редактором.

## Основне правило

Кожна касова операція повинна бути підкріплена правильним типом фіскального чеку через ПРРО. Відсутність чеку або застосування неправильного типу — порушення касової дисципліни.

## Типи чеків

| Тип чеку | Коли застосовується | Хто виконує |
|---|---|---|
| **Чек продажу** | Будь-який продаж товару клієнту | Касир |
| **Чек повернення** | Повернення коштів клієнту за товар | Касир + КЗ |
| **Чек службового внесення** | Поповнення каси розмінним фондом на початку зміни | КЗ |
| **Чек службової видачі** | Виймання готівки з каси (для інкасації або інших цілей) | КЗ |
| **Z-звіт** | Закриття фіскальної зміни ПРРО в кінці дня | Касир / КЗ |
| **X-звіт** | Проміжний звіт про стан каси без закриття зміни | Касир / КЗ |

## Правила застосування

### Чек продажу
- Пробивається при кожному продажу без винятку.
- Товар у чеку повинен точно відповідати фактично відпущеному товару.
- Тип оплати в чеку — відповідно до фактичного платежу клієнта.
- → [Регламент відповідності товару в чеку](/cash/cash-discipline/reg-receipt-item-must-match-actual-goods)

### Чек повернення
- Оформлюється при будь-якому поверненні коштів клієнту.
- Обов'язково прив'язується до оригінального чека продажу (номер чека).
- Виконується тільки з участю КЗ або директора.
- Якщо клієнт повертає лише частину позицій зі старого чека, чек повернення оформлюється тільки на фактично повернені позиції.
- Повне сторно старого чека + новий продаж залишку не використовується як базовий сценарій часткового повернення, якщо немає реальної нової покупки / обміну.
- → [SOP: Виправлення чеку](/cash/receipts/sop-receipt-correction)

### Службове внесення
- Оформлюється при поповненні каси на початку зміни.
- Сума = сума розмінного фонду, що вноситься.

### Службова видача
- Оформлюється при кожному виїмканні готівки з каси.
- Підстава для виїмки обов'язково фіксується.
- Сума службової видачі повинна дорівнювати сумі готівки, яка фізично вилучається з каси.
- Заборонено оформлювати службову видачу на суму, якої фізично немає в касі, або “для вирівнювання залишку”.
- Якщо помилковий документ уже створено — виправлення погоджується з директором / бухгалтерією / BAF-підтримкою; другий фантомний документ не створюється.
- → [SOP: Закриття касової зміни](/cash/shift-closing/sop-shift-closing)
- → [SOP: Звірка каси на початку та в кінці зміни](/cash/shift-closing/sop-cash-reconciliation-opening-closing)

### Z-звіт
- Формується одноразово на кінець кожного робочого дня.
- Після Z-звіту відкрити нову фіскальну зміну можна тільки наступного дня.
- → [SOP: Закриття касової зміни](/cash/shift-closing/sop-shift-closing)

### X-звіт
- Використовується для перевірки поточного стану каси без закриття зміни.
- Не впливає на фіскальний облік.
- Застосовується при звірці в середині зміни або за запитом КЗ.

## Офлайн-режим ПРРО

Якщо під час пробиття чеку ПРРО перейшов в офлайн — чеки продовжують формуватися в офлайн-режимі. Після відновлення зв'язку офлайн-документи надсилаються до ДПС автоматично або вручну.
→ [Інструкція: ПРРО офлайн-режим](/cash/cash-discipline/instruction-prro-offline-mode-in-baf)

## Заборонено

- ❌ Проводити продаж без фіскального чеку.
- ❌ Оформлювати повернення без чеку повернення через ПРРО.
- ❌ Закривати зміну більше одного разу на день.
- ❌ Виймати готівку без оформлення службової видачі.
- ❌ Оформлювати службову видачу, переміщення або інкасацію на суму, яка не відповідає фактично переданій / вилученій готівці.
- ❌ Створювати фантомний касовий документ заднім числом для вирівнювання залишку.
- ❌ При частковому поверненні створювати штучний новий продаж на залишок старого чека, якщо клієнт не робив нову покупку цього дня.
