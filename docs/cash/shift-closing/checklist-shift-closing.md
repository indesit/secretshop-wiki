## Звірення

- [ ] Готівка фактична = готівка за Z-звітом
- [ ] Безготівкові за терміналом = безготівкові за системою
- [ ] Службові внесення перевірені
- [ ] Службові видачі / витрати перевірені
- [ ] Повернення, заміни, покупки для магазину або інші нестандартні операції перевірені
- [ ] Сума службової видачі / переміщення в касу відповідає розрахунку
- [ ] Сума службової видачі / переміщення дорівнює сумі готівки, яка фізично передана / вилучена
- [ ] Фантомних документів “для вирівнювання залишку” не створено
