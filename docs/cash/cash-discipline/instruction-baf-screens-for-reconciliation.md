# Інструкція: де дивитися дані в BAF для звірки каси

> [!WARNING]
> Цей документ має статус `draft`. Не є офіційним до підтвердження редактором. Частина екранів (готівкова виручка за день, закриття зміни/Z-звіт) ще не задокументована — див. розділ "Відкриті питання" в кінці.

## Мета

Показати, де саме в BAF знаходиться кожен екран, потрібний для [звірки каси](/cash/shift-closing/sop-cash-reconciliation-opening-closing) і для мінімального набору скріншотів при ескалації підозри на помилку BAF.

## 1 — Екран зміни / касового дня

Відкривається як картка поточної зміни (наприклад, "River Mall (Магазин), Смена № НФНФ-012644").

Що видно:
- назва магазину і номер зміни, дата — у заголовку картки;
- поточний оператор/адміністратор — випадаюче поле над сумою в касі;
- **поточна сума готівки в касі** — блок "В кассе: N";
- список чеків за поточну зміну (номер чека, сума) — під сумою в касі, фільтр "За текущую смену".

Це основний екран для скріншота "зміна / касовий день" і "дата, магазин, каса".

## 2 — Готівкова виручка за дату

> [!NOTE]
> Відкрите питання — див. "Відкриті питання" нижче. Явного окремого екрана з підсумком готівкової виручки за день поки не знайдено; список чеків на екрані зміни (п.1) показує окремі чеки, але не завжди зручний підсумок для звірки.

## 3 — Службове внесення готівки

1. На екрані зміни (п.1) натисніть іконку внесення грошей біля панелі "В кассе".
2. Відкриється вікно **"Внесение наличных"**.
3. Натисніть **"Внести деньги"**, вкажіть суму.
4. Документ з'явиться в таблиці цього вікна (Дата / Номер / Каса ККМ / Сума).

## 4 — Службова видача / витрати

Два способи в BAF:

**А. Швидка виїмка з екрана зміни:**
1. На екрані зміни (п.1) натисніть іконку виїмки біля панелі "В кассе" (сусідня з іконкою внесення).
2. Відкриється вікно **"Сумма выемки, грн."** — вкажіть суму, підтвердіть.

**Б. Документ через "Документи по касі":**
1. Перейдіть у розділ **Гроші → Документи по касі**.
2. Натисніть **"Расход"** — випаде меню типів: Поставщику, На расходы, Нашей организации, Зарплата по ведомости, Зарплата сотруднику, Прочему контрагенту (учредителю), Покупателю (возврат), Взнос наличными в банк, Прочий расход, Подотчетнику, Перемещение в кассу ККМ, Налоги.
3. Для службової видачі на операційні витрати — оберіть **"На расходы"**.
4. Для інкасації / переміщення в касу (Крок 5 SOP закриття зміни) — оберіть **"Перемещение в кассу ККМ"**.

> [!IMPORTANT]
> "На расходы" і "Перемещение в кассу ККМ" — це різні типи документів у BAF, що підтверджує розмежування термінів [службова видача vs інкасація](/cash/shift-closing/sop-cash-reconciliation-opening-closing) у SOP.

У розділі "Документи по касі" праворуч є зведена **"Ведомость за [дату]"** по конкретній касі: Начало дня / Поступило / Списано / Конец дня — зручно для звірки руху готівки за день по цій касі.

## 5 — Закриття зміни / Z-звіт / переміщення в касу

> [!NOTE]
> Відкрите питання — див. "Відкриті питання" нижче. Явного окремого екрана закриття зміни з підсумковою готівковою сумою (аналог Z-звіту) поки не знайдено.

## 6 — Дата, магазин, каса

Видно на тому самому екрані зміни (п.1) — у заголовку картки.

## Мінімальний набір скріншотів для ескалації

Відповідно до [SOP звірки каси](/cash/shift-closing/sop-cash-reconciliation-opening-closing):

1. Екран зміни (п.1) — магазин, дата, номер зміни, сума в касі.
2. Готівкова виручка за дату — TODO, див. відкрите питання.
3. Вікно "Внесение наличных" (п.3), якщо були внесення.
4. Вікно "Сумма выемки" або документ "На расходы" (п.4), якщо були видачі.
5. Закриття зміни / переміщення в касу — TODO, див. відкрите питання; тимчасово можна докласти "Перемещение в кассу ККМ" з "Документи по касі" (п.4) і "Ведомость за [дату]" з того ж розділу.
6. Той самий екран зміни (п.1), де видно дату, магазин, касу.

## Відкриті питання

- Немає підтвердженого екрана з готівковою виручкою за день окремо від списку чеків зміни.
- Немає підтвердженого екрана закриття зміни з підсумковою готівковою сумою (Z-звіт у самому BAF, а не тільки фіскальний чек).
- Потрібно уточнити в BAF-підтримки або бухгалтерії, чи "Ведомость за [дату]" (розділ "Документи по касі") — це і є потрібний підсумковий екран для пп. 2 і 5, чи є окремий звіт.
